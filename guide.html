User Guide

PedalStock keeps track of the parts you have, turns a parts list into a build, and tells you what to order before you start soldering. It runs as an app on iPhone and iPad, and as a web app in any modern browser. This guide covers both. Where something only exists in one, it's marked App or Web.

1. Getting started

PedalStock has three main tabs: Inventory for the parts you own, Builds for the pedals you're making, and Low Stock for what's running low or missing. The app adds a fourth, Resources, with links to forums, layouts and suppliers.

A good first session:

  1. Add your parts, or import them from a spreadsheet (see importing inventory).
  2. Start a build from a parts list: paste it, import a CSV, or scan a schematic.
  3. Open Low Stock → Build Shortages to see what you need to order.

Your data stays with you. The app stores everything on your iPhone or iPad. The web app stores everything in your browser on that computer. There's no account and no server, and the two don't sync on their own. Use export and import to move data between them (see backups and moving your data).

2. Inventory

Adding a part

App: Inventory → + → Add Part. Web: Add Part. Choose a category, then fill in what you know:

  • Value, such as 10k, 2N3904, 1N4148 or B100k. For capacitors you enter a capacitance (100nF), a type and an optional voltage rating instead.
  • Name is required in the app's Inventory form. On the web, and when you create a new part from a build, you can leave it blank and it's made from the value and category, such as "10k Resistor".
  • Quantity is how many you have, and low-stock threshold is the count at or below which the part counts as low.
  • Commonly used marks a part you always want in stock. Only commonly used parts appear on the Low Stock list, and they get a star in Inventory.
  • Supplier, price, purchase link and notes are for your own reference.

Values are read the way builders write them, so 4k7, 4.7k and 4.7kΩ are the same resistor, and 1K ohm finds a part saved as 1k.

Finding parts

Inventory is grouped by category. Every section starts collapsed: tap a heading to open it. Searching opens every section so no match is hidden. Search looks at names, and for capacitors at every unit, so 22nF finds a part saved as 0.022uF.

A ▲ next to a part means its quantity is at or below its threshold. Tap a part to see its details, the builds it's used in and, for capacitors, its substitutes. Long lists have a back-to-top button at the bottom right.

Importing and exporting inventory

App: Inventory → + → Import Inventory… or Export Inventory…. Web: Import CSV… or Export CSV.

Import reads a CSV saved from Numbers, Excel or Google Sheets. Rows that match a part you already have update it, and the rest are added. Parts match by name, or by category and value. Only the columns in your file are changed: leave out price and existing prices stay as they are.

To add a new order on top of what you already have, use an addQuantity column instead of quantity. See file formats for every column, or start from a CSV template.

3. Capacitors

Capacitor rows show the value in its most natural unit as the title, such as "22 nF Ceramic", with the same value in the other units underneath (0.022 µF · 22000 pF). They're sorted smallest first, then by voltage, so your 10µF electrolytics line up 16V, 25V, 50V.

Each capacitor has a type: Film Box, Greenie, Film, Ceramic, Silver Mica, Polarized, Tantalum, Electrolytic or Other. Types matter for substitutes. Film types and ceramics can stand in for each other, but electrolytic, tantalum and polarized caps are never suggested as swaps for anything else. If a part's type is Other and its name says "box film", "greenie", "MLCC" and so on, PedalStock fills the type in from the name.

The voltage rating is shown in Build Shortages and on build pages, so you can tell a 16V cap from a 25V one at a glance. Parts with the same value but different voltages are treated as different parts.

4. Duplicate parts

Imports and scans can leave you with the same part twice, for example "10k" and "10kΩ Resistor". When PedalStock spots likely duplicates, a "possible duplicates" card appears at the top of Inventory. You can also open the review any time: app, Inventory → + → Find Duplicates…; web, Find Duplicates….

  • Untick any part in a group that doesn't belong.
  • Tap Merge and choose which part to keep. Quantities are added together, and builds that used the others now use the kept part.
  • Tap Not Duplicates to stop that group appearing again, until another matching part is added. Show Dismissed Groups brings them back.

Capacitors with different voltages or types aren't grouped as duplicates.

5. Starting a build

On the Builds tab (app: tap +), pick how to begin:

OptionUse it for
New BuildAn empty build you'll add parts to by hand.
Paste BOM…A parts list copied from a forum post, build doc or web page, one part per line: R1 10k, C3 100nF, Q1 2N3904 x2.
Scan Schematic/Layout…A schematic, vero or stripboard layout, or kit build doc as an image, SVG or PDF. See scanning.
Import Project… AppA CSV BOM or a PedalStock project JSON file.
Import Builds…A builds file from Export Builds, or a CSV BOM, which becomes a new build named after the file. See the BOM templates.

Every part in the list is matched against your inventory. Parts you don't have are added to inventory with a quantity of 0, so they show up as shortages. Lines for the same part, such as R1 10k and R4 10k, are combined into one row with the total quantity.

Starting a build doesn't take anything out of inventory. Parts are only taken when you tick them as installed, or when you mark the build complete.

6. Scanning schematics and layouts

Scanning reads the printed labels and values on a schematic or layout, such as R1 next to 10k, and pairs each label with the value nearest to it. It works on PNG, JPG, SVG and PDF files. The app can also scan paper with the camera; see schematics and layouts. The file is read on your device and never uploaded.

PDFs that contain real text, such as kit build docs, are read from that text, which is fast and exact. Scanned PDFs and images go through text recognition. That's very good in the app, and good but less accurate on the web.

Review Scan

Nothing is imported until you've checked it on the Review Scan screen:

  • Recognized: each label with the value it was paired with. Fix any value that was misread. To drop a line, swipe it in the app or tap ✕ on the web.
  • Labels without a value: labels the scan couldn't pair. Type a value to include the part, or leave it blank to skip it.
  • Values without a label: leftover text such as voltages and page numbers, plus real values whose label was missed. Use Use… to give a value to one of those labels, or to add it as a part of a chosen category.

The scanned file is kept with the build, under Schematics & Layouts.

Tips for better scans

  • Use the sharpest version you can find. A PDF from the designer beats a screenshot, and a screenshot beats a photo.
  • Pots labelled by their control name (GAIN, TONE, VOLUME, DEPTH and so on) are recognized when a pot value like B100k is next to them.
  • Values printed with Ω, such as 470Ω, are often read with a stray character. PedalStock fixes the common cases, but check resistor values in the review.
  • A part drawn only as a symbol, with no printed label, can't be scanned. Add it from the leftover values or by hand.

7. Working on a build

Open a build from the Builds tab. At the top you'll find its status, its notes and its schematics and layouts. Tap Edit to rename it or change its circuit type and notes.

Status

A build is Planning, In Progress or Completed. Ticking the first part or stage moves a Planning build to In Progress for you.

Parts

Parts are grouped by category in collapsible sections. A ▲ on a section or row means you don't have enough in stock. On each part row:

  • Tick the circle when you install the part. It comes out of inventory then. Untick it to put it back.
  • − and + change how many the build needs. In the app, tap the count itself to pick a number. You can only change the count of a part that isn't ticked, so untick it first if you need to.
  • Tap the part's name (marked ⇄) to use a different part instead, such as a TL062 in place of a TL072. You can pick any part in inventory or create a new one, even if you have none in stock.
  • Remove it from the build: swipe left or touch and hold in the app, or tap ✕ on the web. Anything it took from inventory goes back.

To add parts, use Add Part, Paste More Parts… Web, Add from Scan… Web or Import Parts From PDF or Image… App. Parts already in the build have their count raised instead of getting a second row. If a build ends up with the same part on two rows, a Merge Duplicates button appears above the parts list.

Progress

The progress bar counts installed parts and these stages: Parts gathered, Enclosure drilled, Enclosure painted / finished, Board populated, Off-board wiring (pots, jacks, switch, LED, power), Boxed up and Tested. Tick stages as you go.

8. Schematics and layouts

Each build has a Schematics & Layouts section for the files you build from. Scanned files are added here automatically. You can also:

  • Attach a PDF, image or SVG yourself. In the app, use Attach Schematic or Layout and choose a file or a photo. On the web, use Attach File….
  • Scan with Camera… App to photograph a paper schematic as a clean PDF.
  • Find Schematic or BOM Online… App searches build-doc sites for the build's name. You pick which result to download, attach or import parts from.
  • Tap a file to open it. In the app, touch and hold a file to rename or delete it. On the web, use Download, Rename or ✕.

Deleting a build deletes its files too.

9. Finishing, reopening and deleting

  • Mark Build Complete takes any parts you haven't ticked out of inventory, ticks every stage and locks the build.
  • Reopen Build moves a completed build back to In Progress. You choose whether to return its parts to inventory or keep inventory as it is.
  • Delete Build: if the build has taken parts, you choose whether to return them to inventory or keep them as used. In the app you can also swipe a build on the Builds tab to delete it.

10. Low Stock and Build Shortages

The Low Stock tab has two lists:

  • Low Stock: commonly used parts at or below their low-stock threshold.
  • Build Shortages: everything your Planning and In Progress builds need more of than you have. Each row shows the part, how many you have and need, how many you're short, and which builds need it.

Shortages are added up across all open builds. If two builds each need five of a part and you have eight, each build looks covered on its own, but you're two short overall. Use the Build menu at the top to see one pedal at a time. The web version remembers your choice.

To order, share the shortage list from the app or use Copy Shopping List on the web. Tap a shortage to use a part you already have instead (see substitutes).

11. Substitutes

When a part is short, PedalStock can suggest one you have that will do the job. For capacitors, that's the same value in an interchangeable type: box film, greenies and other film first for most values, and ceramic or silver mica first below 1nF. Electrolytic, tantalum and polarized caps are never swapped. A short part on a build shows a one-tap Use … instead suggestion when you have enough of an interchangeable part, and a capacitor's part page lists its substitutes, best first.

From Build Shortages, or by tapping a part's name on a build, you can pick any part as the replacement. That includes ICs and transistors (a TL062 for a TL072), parts you have none of, or a new part. You choose which builds the swap applies to, and a note is added to each build.

12. Resources App

The Resources tab collects links to forums, traced schematics, layout sites, PCB and kit makers, and parts suppliers. Copy a parts list from any of them and use Paste BOM… to bring it in.

13. Backups and moving your data

The app's data is included in your iPhone or iPad backup. The web app's data lives in the browser on one computer, and clearing that browser's site data deletes it, so export now and then.

To move everything to another device, or between the app and the web:

  1. Export your inventory. App: Inventory → + → Export Inventory…. Web: Export CSV.
  2. Export your builds. App: Builds → + → Export Builds…. Web: Export Builds. The file includes each build's parts, progress, notes and attached files.
  3. On the other device, import the inventory first, then the builds, so each build's parts match up.

Importing the same builds file twice doesn't create copies: builds that are already there are skipped.

14. File and BOM formats

CSV templates

Start from a template: download it, open it in Numbers, Excel or Google Sheets, replace the example rows with your own, and save or export it as CSV.

  • Inventory template Every inventory column, with example parts. Use with Import Inventory… (app) or Import CSV… (web).
  • Inventory order template Adds a new order on top of what you have, using addQuantity.
  • BOM template, PedalStock columns One row per part with category and quantity. Use with Import Builds… or Import Project….
  • BOM template, by part label The usual Designator, Value, Qty layout, as many kits and design tools export it.

A BOM import names the new build after the file, so rename the file to the pedal's name first, for example Fuzz Face.csv.

Inventory CSV

A header row is required. Column names aren't case-sensitive, and spaces and underscores are ignored.

ColumnNotes
name, categoryRequired. Category is one of Resistor, Capacitor, Potentiometer, IC, Transistor, Diode, LED, Knob, Footswitch, Jack, Enclosure, Wire, PCB, Hardware or Other.
quantitySets the count you have.
addQuantityAdds to the count you have. Use this for a new order.
valueFor non-capacitors: 10k, 2N3904, B100k.
capacitance, capacitorType, voltageRatingFor capacitors: 100nF, Film Box, 25V. Nicknames like "box film" or "MLCC" work for the type.
lowStockThreshold, commonlyUsedLow-stock warning level, and yes/true/1 to mark a part commonly used.
supplier, price, purchaseLink, notesOptional details.

CSV BOMs (Import Builds, Import Project)

Two layouts work. The first uses PedalStock's own columns, category and quantity, plus optional value, capacitance, capacitorType and voltageRating:

category,value,capacitance,capacitorType,voltageRating,quantity
Resistor,10k,,,,2
Capacitor,,10uF,Electrolytic,25V,1

The second is the usual BOM layout, by part label. It needs a Designator (or Ref, Reference, Part) column and a Value column, with an optional Qty. Without Qty, the quantity is the number of labels in the cell:

Designator,Value,Qty
"R1, R4",1M,2
C3,100nF,1
IC1,TL072,1
GAIN,B500k,1

A file with no header row is read line by line, like Paste BOM.

Builds file

Export Builds writes a .json file holding every build with its parts, progress, stages, notes and attached files. The app and the web app read and write the same file.
