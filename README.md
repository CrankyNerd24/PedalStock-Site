# PedalStock site

The public marketing, support and privacy pages for PedalStock. Plain HTML and one stylesheet, no build step, so GitHub Pages can serve the repository root as is.

- `index.html`: the marketing page
- `support.html`: help and contact
- `privacy.html`: the privacy policy
- `style.css`: colors and type from the PedalStock design system
- `app-icon.svg`: the app icon, also the favicon
- `CNAME`: serves the site at pedalstockapp.com
